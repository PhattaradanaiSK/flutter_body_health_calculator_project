# Body ว้าว — แอปคำนวณ BMI และ BMR (Assignment 04)

แอป Flutter สำหรับ Android ใช้คำนวณ BMI และ BMR ตามแบบงาน มีหน้า About, BMI และ BMR พร้อมใช้งานแบบออฟไลน์ โดยไม่ต้องใช้ Backend, Database, Authentication, API key หรือดาวน์โหลดฟอนต์ขณะใช้งาน

## ติดตั้งและรัน

ติดตั้ง Flutter stable และ Android SDK จากนั้นเปิดโฟลเดอร์โปรเจกต์และรัน:

```bash
flutter pub get
flutter run
```

เลือก Android emulator หรือโทรศัพท์ Android ที่เชื่อมต่อไว้ ตรวจรายชื่ออุปกรณ์ได้ด้วย `flutter devices` ฟอนต์ Kanit และภาพประกอบรวมอยู่ในโปรเจกต์แล้ว

## ฟังก์ชันหลัก

- เลือกดูหน้า About, BMI และ BMR จากแถบนำทางด้านล่าง
- คำนวณ BMI จากน้ำหนัก (kg) และส่วนสูง (cm) พร้อมแสดงค่า 2 ตำแหน่งและหมวดน้ำหนัก
- คำนวณ BMR โดยเลือกเพศและกรอกน้ำหนัก ส่วนสูง และอายุ เพื่อแสดงผลเป็น kcal/day
- ล้างข้อมูลและผลลัพธ์ได้ ตรวจสอบอินพุตให้เป็นค่าบวกที่ถูกต้อง และอายุต้องเป็นจำนวนเต็ม
- ใช้งานออฟไลน์ โดยข้อมูลไม่ถูกส่งไปยังบริการออนไลน์

### สูตรคำนวณ

BMI = น้ำหนัก (kg) ÷ (ส่วนสูง (m) × ส่วนสูง (m))

| ค่า BMI ก่อนปัดแสดงผล | การแปลผล |
|---|---|
| < 18.5 | น้ำหนักต่ำกว่าเกณฑ์ |
| ≥ 18.5 และ < 23 | น้ำหนักสมส่วน |
| ≥ 23 และ < 25 | น้ำหนักเกิน |
| ≥ 25 และ < 30 | โรคอ้วนระดับ 1 |
| ≥ 30 | โรคอ้วนระดับ 2 หรืออ้วนมาก |

- BMR ชาย = `88.362 + 13.397 × kg + 4.799 × cm − 5.677 × อายุ`
- BMR หญิง = `447.593 + 9.247 × kg + 3.098 × cm − 4.330 × อายุ`
