# เครดิตภาพและฟอนต์

## ภาพประกอบ

ภาพต้นฉบับอ้างอิงจาก [Figma ของ Assignment 04](https://www.figma.com/design/echDDj4imtfVabmvJ8NuJn). ไฟล์อ้างอิงอยู่ใน `docs/figma_reference/` และภาพที่ใช้ในแอปอยู่ใน `assets/images/` โดยเป็นภาพที่ครอปจากต้นฉบับเพื่อใช้ในหน้าจอแอป

หากต้องการสร้างภาพประกอบซ้ำ ให้ติดตั้ง Python, Pillow และ NumPy (`pip install pillow numpy`) แล้วรัน `python3 tools/extract_figma_assets.py` จากโฟลเดอร์โปรเจกต์

ภาพประกอบใช้ในบริบทของงานเรียน การนำไปใช้นอกเหนือจากงานนี้ควรตรวจสอบสิทธิ์กับเจ้าของต้นฉบับก่อน

## ฟอนต์ Kanit

ไฟล์ `assets/fonts/Kanit-Regular.ttf`, `Kanit-Medium.ttf` และ `Kanit-Bold.ttf` มาจาก [Google Fonts — Kanit](https://github.com/google/fonts/tree/main/ofl/kanit) และใบอนุญาต SIL Open Font License 1.1 รวมอยู่ที่ `assets/fonts/OFL.txt` แอปใช้ฟอนต์ที่รวมไว้ในโปรเจกต์และไม่ดาวน์โหลดฟอนต์ผ่านเครือข่าย
